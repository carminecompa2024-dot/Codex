# Italian Food Cities

A small Node.js web app that accepts Italian cities as input and returns a typical food for each one, complete with a photo. The page includes a fallback dish so you can input any Italian city and still receive a tasty recommendation.

## Running the app

```bash
npm install
npm start
```

Then visit <http://localhost:3000> and enter cities (one per line or comma-separated).

## Data set

The curated list lives in `data/foods.json`. Add more cities, foods, and photo links to expand the results.
